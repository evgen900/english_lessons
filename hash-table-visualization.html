Анализ сложности

    
Почему HashSet — оптимальное решение?


    

      

        
Время · Hash Set

        
O(n)

        
Один проход по массиву. Каждая проверка и вставка в set — O(1) в среднем.

      

      

        
Память · Hash Set

        
O(n)

        
В худшем случае храним все n элементов в множестве.

      

      

        
Время · Brute Force

        
O(n²)

        
Два вложенных цикла — сравниваем каждый с каждым.

      

      

        
Время · Sort

        
O(n log n)

        
Сортировка + один проход. Быстрее brute force, но медленнее set.
